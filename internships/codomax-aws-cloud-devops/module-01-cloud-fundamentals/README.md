# Module 01: AWS & Cloud Fundamentals

## Overview

This module introduces the fundamental concepts of cloud computing and Amazon Web Services (AWS). It focuses on understanding cloud service models, deployment models, AWS global infrastructure, core AWS services, and basic cloud architecture.

**Program:** Codomax Digital Solutions — AWS Cloud & DevOps Internship  
**Module:** 01 — AWS & Cloud Fundamentals  
**Duration:** October 26 – November 23, 2026 *(overall internship period; module-specific dates may differ)*

## Learning Objectives

- Understand cloud computing and its key benefits.
- Differentiate between Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS).
- Understand public, private, and hybrid cloud deployment models.
- Explain AWS Regions, Availability Zones, and AWS global infrastructure.
- Explore the AWS Management Console and major AWS services.
- Understand the fundamentals of designing a basic AWS architecture.
- Identify basic security, access-control, and monitoring considerations in cloud environments.

## Topics Covered

### 1. Cloud Computing Fundamentals
- Definition and characteristics of cloud computing
- Benefits and common use cases
- IaaS, PaaS, and SaaS service models
- Public, private, and hybrid cloud deployment models

### 2. AWS Global Infrastructure
- AWS Regions
- Availability Zones
- AWS global infrastructure and service availability

### 3. Introduction to AWS Services
- Amazon EC2 — virtual servers
- Amazon S3 — object storage
- Amazon VPC — network isolation and configuration
- AWS IAM — identity and access management
- Amazon RDS — managed relational databases
- Amazon CloudWatch — monitoring and observability

### 4. Basic AWS Architecture
The architecture exercise explores how AWS components can work together to support a basic web application.

The conceptual design includes:
- A VPC providing a logically isolated network.
- A public subnet hosting a web server on Amazon EC2.
- A private subnet hosting a database such as Amazon RDS.
- Security groups controlling permitted network traffic.
- AWS IAM roles defining permissions for AWS resources.
- Amazon CloudWatch for monitoring and operational visibility.

**Note:** This is a conceptual architecture unless otherwise stated in the accompanying diagram and implementation notes. It should not be interpreted as a deployed or production-ready environment.
